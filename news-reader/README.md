# FE Project Capstone – News Reader App

## Overview
A responsive React application built with Vite and Tailwind CSS that fetches and displays news articles from an external API. Users can search, filter by category, and view detailed articles.

## Features
- Fetch top headlines, search articles, and filter by category.
- Responsive design (mobile-first, adapts to desktop).
- Interactive UI with hover effects and transitions.
- Article detail view with full content.
- Error handling and loading states.
